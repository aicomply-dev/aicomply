# FORM-AI-REG-001 : Formulaire d'enregistrement dans la base de données UE

**ID du formulaire :** FORM-AI-REG-001
**Nom du formulaire :** Formulaire d'enregistrement dans la base de données UE
**Version :** 1.0
**Date d'entrée en vigueur :** [À compléter]
**Norme associée :** STD-AI-011 : Norme d'enregistrement IA
**Procédure associée :** PROC-AI-REG-001 : Procédure d'enregistrement

---

## Objectif

Ce formulaire recueille toutes les informations requises pour l'enregistrement des systèmes d'IA à haut risque dans la base de données UE conformément à l'article 71 du règlement IA de l'UE. Complétez ce formulaire avant de placer un système d'IA à haut risque sur le marché de l'Union ou de le mettre en service.

## Instructions

1. Compléter toutes les sections applicables en fonction de votre rôle (Fournisseur ou Déployeur)
2. S'assurer que les informations correspondent à la documentation technique
3. Soumettre à la base de données UE avant la mise sur le marché/le déploiement
4. Mettre à jour l'enregistrement pour toute modification substantielle
5. Conserver une copie de l'enregistrement pendant 10 ans
