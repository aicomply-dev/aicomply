## 1. PROPÓSITO Y ALCANCE

### 1.1 Propósito

Este procedimiento establece requisitos para asegurar que el personal involucrado con sistemas de IA tenga capacitación y competencias adecuadas según los requisitos del Artículo 4 (alfabetización en IA) y Artículo 14 (supervisión humana) del Reglamento de IA de la UE.

### 1.2 Alcance

Este procedimiento aplica a:
- Desarrolladores de IA y científicos de datos
- Operadores y responsables del despliegue de sistemas de IA
- Personal de supervisión humana
- Gerencia con responsabilidades en IA
- Usuarios finales de sistemas de IA de alto riesgo

---

| Rol | Responsabilidad |
|------|----------------|
| **Gestor de Capacitación** | Desarrollar y mantener programa de capacitación |
| **Recursos Humanos** | Rastrear registros de capacitación; asegurar cumplimiento |
| **Gerentes de Departamento** | Asegurar que el personal complete la capacitación requerida |
| **Empleados** | Completar capacitación asignada; mantener competencia |

---

## 3. REQUISITOS DE CAPACITACIÓN

### 3.1 Categorías de Capacitación

| Categoría | Audiencia Objetivo | Temas |
|----------|-----------------|--------|
| **Concientización en IA** | Todos los empleados | Fundamentos de IA, resumen del Reglamento de IA de la UE, política organizacional de IA |
| **Alfabetización en IA** | Usuarios y operadores de IA | Comprensión de resultados de IA, limitaciones, uso apropiado |
| **IA Técnica** | Desarrolladores, científicos de datos | Prácticas de desarrollo, requisitos de cumplimiento |
| **Supervisión Humana** | Personal de supervisión | Monitoreo, intervención, procedimientos de anulación |
| **Gestión de IA** | Gerentes y ejecutivos | Gobernanza, riesgo, supervisión del cumplimiento |

### 3.2 Matriz de Capacitación Basada en Roles

| Rol | Concientización | Alfabetización | Técnica | Supervisión | Gestión |
|------|-----------|----------|-----------|-----------|------------|
| Todos los Empleados | Requerida | - | - | - | - |
| Usuarios de IA | Requerida | Requerida | - | - | - |
| Personal de Supervisión | Requerida | Requerida | - | Requerida | - |
| Desarrolladores | Requerida | Requerida | Requerida | - | - |
| Gerentes | Requerida | Requerida | - | - | Requerida |
| Ejecutivos | Requerida | - | - | - | Requerida |

### 3.3 Requisitos Adicionales para IA de Alto Riesgo

El personal que opera sistemas de IA de alto riesgo debe demostrar:
- Comprensión de capacidades y limitaciones del sistema
- Capacidad para interpretar correctamente los resultados de IA
- Competencia para realizar funciones de supervisión humana
- Conocimiento de procedimientos de intervención y anulación

---

## 4. PROCESO DE CAPACITACIÓN

### 4.1 Evaluación de Necesidades de Capacitación

**Paso 1: Identificar Necesidades de Capacitación**
1. Revisar roles y responsabilidades laborales
2. Identificar sistemas de IA con los que el personal interactúa
3. Evaluar niveles actuales de competencia
4. Identificar brechas de capacitación
5. Documentar requisitos de capacitación

**Paso 2: Crear Plan de Capacitación**
1. Asignar capacitación requerida a roles
2. Establecer plazos de finalización
3. Programar sesiones de capacitación
4. Asignar recursos de capacitación

### 4.2 Impartición de Capacitación

**Métodos de Capacitación:**
| Método | Caso de Uso |
|--------|----------|
| Aprendizaje en línea | Concientización, alfabetización básica |
| Dirigida por instructor | Técnica, supervisión |
| Práctica | Operación específica del sistema |
| En el trabajo | Desarrollo de habilidades prácticas |
| Certificación | Competencias especializadas |

### 4.3 Evaluación de Competencias

**Paso 3: Evaluar Competencia**
1. Administrar evaluaciones/pruebas
2. Evaluar demostraciones prácticas
3. Revisar desempeño en el trabajo
4. Documentar resultados de evaluación
5. Identificar necesidades de remediación

**Criterios de Aprobación:**
| Nivel de Capacitación | Puntuación Mínima |
|----------------|---------------|
| Concientización | 70% |
| Alfabetización | 80% |
| Técnica | 85% |
| Supervisión | 90% |

### 4.4 Registros de Capacitación

**Paso 4: Mantener Registros**
Para cada empleado, mantener:
- Cursos de capacitación completados
- Fechas de finalización
- Puntuaciones de evaluación
- Certificaciones obtenidas
- Fechas de vencimiento de capacitación de actualización
