## Propósito

Esta lista de verificación proporciona un método sistemático para evaluar la eficacia de los controles de riesgo implementados para sistemas de IA. Utilice esta lista de verificación para verificar que los controles estén adecuadamente diseñados, correctamente implementados y operando de manera eficaz para mitigar los riesgos identificados.

## Instrucciones

1. Complete esta lista de verificación periódicamente para todos los sistemas de IA con controles implementados
2. Frecuencia: IA de Alto Riesgo (trimestral), Riesgo Limitado/Mínimo (anual)
3. Documente evidencia para cada control evaluado
4. Aborde cualquier brecha o deficiencia identificada
5. Actualice las evaluaciones de riesgos basándose en los hallazgos
