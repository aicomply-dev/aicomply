## Propósito

Esta lista de verificación proporciona una guía sistemática para realizar evaluaciones de riesgos de sistemas de IA según los requisitos del Reglamento de IA de la UE. Use esta lista junto con el Formulario de Evaluación de Riesgos (FORM-AI-RM-001) para garantizar una identificación y evaluación integral de riesgos.

## Instrucciones

1. Complete todas las secciones aplicables
2. Marque cada elemento como Completo, Parcial, No Aplicable (N/A) o No Iniciado
3. Documente evidencia y notas para cada elemento
4. Aborde todas las brechas antes de pasar a la siguiente fase del ciclo de vida
5. Revise y actualice en cada fase del ciclo de vida
